WHAT REMAINS — FILM MARKET MICROSITE

This is a static website for GitHub Pages. Keep the folder structure intact.

FILES
- index.html: the complete website
- assets/: poster, seven original film stills, and the optimised film-score excerpt

PUBLISHING / UPDATING ON GITHUB PAGES
1. Open the public repository: https://github.com/bingorav/What-Remains
2. Open the repository's main page and choose Add file > Upload files.
3. Upload the updated index.html and the complete assets folder, including what-remains-score.mp3.
4. If GitHub asks whether to replace existing files, confirm the replacements.
5. Commit the changes to the main branch. GitHub Pages will publish the update at:
   https://bingorav.github.io/What-Remains/

IMPORTANT
- The trailer is embedded from Vimeo video ID 1246157962.
- The score excerpt is a 30-second MP3 made from the supplied WAV, starting at 00:20, with gentle fades and web-optimised encoding.
- Music does not autoplay. Visitors start or pause it using the small control at the bottom-right of the page.
- The gallery uses a regular three-column desktop / two-column mobile grid. Each still displays at its original aspect ratio, without cropping or stretching.
- The poster and all seven stills are unchanged.

The site is plain HTML/CSS/JavaScript and requires no build step or paid hosting.

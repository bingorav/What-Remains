WHAT REMAINS — FREE FILM-MARKET MICROSITE
==========================================

CONTENTS
- index.html
- assets/poster.jpg
- assets/still-01.jpg ... still-07.jpg

CURRENT STATUS
This is a responsive, single-page website built with your supplied poster and stills.
The Vimeo player is currently a visual placeholder because a Vimeo URL/embed code has
not yet been supplied. The synopsis and director's statement are based on Nimoli docs.pdf.

BEFORE PUBLISHING
1. Send the Vimeo link (or Vimeo embed code). The trailer placeholder will be replaced
   with the actual embedded player.
2. Confirm the film's final technical details (runtime, language, year, country) if you
   want them displayed. They have deliberately not been invented here.
3. Confirm whether the cast and producer credits shown are correct.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in or create a free account at https://github.com/
2. Create a new public repository named: what-remains
3. Upload the CONTENTS of this folder (index.html and the assets folder).
   Do not upload only the ZIP file.
4. In the repository, open Settings -> Pages.
5. Under "Build and deployment", select "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. Your address will be similar to:
   https://YOUR-USERNAME.github.io/what-remains/

QR CODE
Only create the final QR code after the GitHub Pages URL is live and tested.
Use a free QR generator and point it to the exact published URL. Test the QR code
on at least two phones before printing.

IMPORTANT
- The site is static; it does not collect visitor data.
- GitHub Pages is free for public repositories, subject to GitHub's current terms.
- No custom domain is included; the free GitHub Pages URL is used.
